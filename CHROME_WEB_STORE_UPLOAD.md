# Chrome Web Store upload checklist

1. Open the Chrome Web Store Developer Dashboard.
2. Choose **New item**.
3. Upload `ao3-exact-title-search-extension-v3.2.1.zip`.
4. Copy the listing fields from `STORE_LISTING.md`.
5. Upload the 128 × 128 store icon from `extension/assets/icon-128.png`.
6. Complete the privacy practices form using the manifest and disclosure in `STORE_LISTING.md`.
7. Save the draft and review every field.
8. Submit for review.

Account registration, payment, legal agreements, privacy declarations, and final submission must be completed by the account owner.
