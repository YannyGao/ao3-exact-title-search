# AO3 Exact Title Search

一个 AO3 标题严格连续匹配搜索工具。仓库包含两个版本：

- `extension/`：保留 AO3 原生界面，只在后台把顶部搜索改成标题连续精确匹配。
- `docs/`：GitHub Pages 静态公开入口，将精确标题查询发送到 AO3。
- `public/` + `server.mjs`：本地镜像版本，在自定义页面中读取和展示 AO3 搜索结果。

## Browser extension

扩展不会添加搜索面板或修改 AO3 的页面文字、布局与样式。安装后继续使用 AO3 原本的顶部搜索框即可。它不申请账号、存储、浏览历史或跨站访问权限，只在 `archiveofourown.org` 上运行。

## 公开版本

GitHub Pages 版本不使用账号、Cookie 或服务器，不保存搜索记录。由于浏览器跨域限制，提交搜索后会前往 AO3 查看结果。

## 启动

需要 Node.js 18 或更新版本。在本文件夹打开终端并运行：

```bash
npm start
```

然后在浏览器打开：

```text
http://127.0.0.1:4173
```

不需要安装依赖。

## 工作方式

页面把搜索文字作为 AO3 的标题短语查询，再对返回的每篇作品标题进行一次连续字符串校验。例如搜索 `羡爆`：

- `前缀羡爆后缀` 会显示。
- `前缀爆羡后缀` 不会显示。
- `前缀羡/爆后缀` 不会显示。

搜索请求只从你的本机服务器发送到 `archiveofourown.org`。工具不使用 AO3 账号、Cookie 或 API key，也不保存搜索记录。
